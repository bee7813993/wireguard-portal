# 利用ガイド — WireGuard Portal

自宅・社内の PC で動いている Web サーバーを、インターネットに公開するための手順です。

---

## 必要なもの

| 項目 | 内容 |
|------|------|
| PC の OS | Windows 10 / 11 |
| ソフトウェア | [WireGuard for Windows](https://www.wireguard.com/install/)（無料） |
| Web サーバー | XAMPP など。待ち受けポートは設定生成時に指定できます（既定: **80**） |
| ポータル URL | 管理者から共有された URL |

---

## STEP 1 — ポータルで設定ファイルを作成する

1. 管理者から共有されたポータルの URL をブラウザで開きます。
2. 「**公開ポート番号**」に、使用するポート番号（例: `11090`）を入力します。  
   ※ ポート番号は管理者に確認してください。他の利用者と重複できません。  
   ※ サーバー上で既に使用されているポート番号など、指定できないポート番号があります。エラーが表示された場合は別の番号を試してください。
3. 「**転送先ポート**」を確認します。これは **自分の PC 側で Web サーバーが待ち受けているポート番号** です。  
   ※ 初期値は `80` です。XAMPP を既定のまま使う場合はそのままで構いません。  
   ※ `8000` や `3000` など 80 以外で動かしている場合は、その番号に変更してください。
4. 「**設定を生成する**」をクリックします。
5. 「**↓ wg-client_11090.conf をダウンロード**」をクリックしてファイルを保存します。

生成後、「外部ポート 11090 → PC (10.0.0.2) のポート 80 に転送されます。」のように転送内容が表示されるので、意図したポートになっているか確認してください。

> 同じポート番号で再生成すると以前の設定は無効になります。再インポートが必要です。

### 削除トークンが表示された場合（管理者の設定による）

設定生成後に「**削除トークン**」が黄色い枠で表示されることがあります。  
これは**この画面を閉じると二度と表示されません**。

- メモ帳などに必ずコピーして保存してください
- 使用をやめるときに設定を削除する際に必要になります
- 同じポートで再生成すると新しいトークンに更新されます（古いトークンは無効になります）

---

## STEP 2 — WireGuard をインストールする

まだインストールしていない場合のみ。

1. https://www.wireguard.com/install/ を開きます。
2. 「Windows Installer」をダウンロードして実行します。
3. 「次へ」を押し続けてインストール完了。

---

## STEP 3 — 設定ファイルをインポートする

WireGuard を起動すると最初は空の画面が表示されます。

![WireGuard 起動直後](images/step3-empty.png)

1. 画面中央の「**ファイルからトンネルをインポート**」をクリックします。  
   ※ または左下「**トンネルの追加 ▼**」→「**ファイルからインポート**」
2. ダウンロードした `wg-client_11090.conf` を選択して「**開く**」をクリックします。
3. 左側のリストに `wg-client_11090` が追加されれば成功です。

![インポート完了後](images/step3-imported.png)

右側に以下の情報が表示されます。

| 項目 | 表示内容 |
|------|---------|
| 状態 | 無効 |
| アドレス | `10.100.10.x/24` |
| DNS サーバー | `1.1.1.1` |
| ピア / エンドポイント | `[サーバーアドレス]:51821` |

---

## STEP 4 — トンネルを有効化する

1. 左のリストで `wg-client_11090` を選択します。
2. 「**有効化(A)**」ボタンをクリックします。

![トンネル有効化後](images/step4-connected.png)

接続が成功すると：

- 左側のアイコンが **緑色のシールド** に変わります。
- 状態が「**有効**」になります。
- 数秒後に「**直近のハンドシェイク: ○秒前**」が表示されます。

> ハンドシェイクが表示されない場合は[トラブルシューティング](#トラブルシューティング)を参照してください。

---

## STEP 5 — Web サーバーを起動する

STEP 1 で指定した **転送先ポート**（初期値は 80）で Web サーバーを起動します。

**XAMPP の場合:**
1. XAMPP Control Panel を開く
2. 「Apache」の「**Start**」をクリック
3. ステータスが緑になれば OK

XAMPP は既定でポート 80 を使うため、転送先ポートを変更していなければこのままで OK です。

**XAMPP 以外の場合:** 使用している Web サーバーを、転送先ポートに指定した番号で起動してください。番号が食い違っているとアクセスできません。

---

## STEP 6 — 外部からアクセスして確認する

ブラウザで以下の URL にアクセスします：

```
http://[管理者から教えてもらったサーバーアドレス]:[ポート番号]
```

例: `http://example.com:11090`

スマートフォンや別の端末からアクセスして、自分の PC の Web サーバーが表示されれば完成です。

---

## PC を再起動したときは

トンネルは PC 再起動で切断されます。再び公開するには：

1. WireGuard を起動する
2. `wg-client_11090` を選択して「**有効化(A)**」をクリック
3. Web サーバーが起動していることを確認する

**自動で再接続したい場合：**  
WireGuard で `wg-client_11090` を右クリック →「**プロパティ**」→「コンピューターの起動時にトンネルを有効化」にチェック

---

## 使用をやめるときは

公開をやめてポータルへの登録を削除する手順です。管理者の設定によって操作が異なります。

### パターン A: ポート番号だけで削除できる場合

1. ポータルの URL をブラウザで開きます
2. ページ下部の「**削除するポート番号**」欄に使用していたポート番号を入力します
3. 「**設定を削除する**」をクリックし、確認ダイアログで「OK」を押します
4. WireGuard のトンネルを「**無効化**」し、トンネルを削除します

### パターン B: 削除トークンが必要な場合

1. ポータルの URL をブラウザで開きます
2. 「**削除するポート番号**」に使用していたポート番号を入力します
3. 「**削除トークン**」に、設定生成時に保存したトークンを入力します
4. 「**設定を削除する**」をクリックし、確認ダイアログで「OK」を押します
5. WireGuard のトンネルを「**無効化**」し、トンネルを削除します

> トークンを紛失した場合は管理者にお問い合わせください。

### パターン C: 管理者のみ削除できる場合

削除フォームが表示されていない場合は、管理者に削除を依頼してください。

### 削除後の WireGuard 側の操作

設定を削除したあとは WireGuard 側も整理してください。

1. WireGuard を開きます
2. 対象のトンネル（例: `wg-client_11090`）を選択します
3. 「**無効化(D)**」をクリックしてトンネルを切断します
4. 左下の「**×**」でトンネルを削除します

---

## トラブルシューティング

### ハンドシェイクが表示されない

| 確認項目 | 対処 |
|---------|------|
| トンネルが「有効」になっているか | 「有効化(A)」を押す |
| Windows ファイアウォールがブロックしていないか | WireGuard をファイアウォールで許可する |
| 設定ファイルが古くなっていないか | ポータルで再生成してインポートし直す |

### 外部からアクセスしても自分のサイトが表示されない

1. WireGuard のトンネルが「**有効**」になっているか確認
2. Web サーバー（Apache 等）が **起動中** か確認
3. Web サーバーの待ち受けポートが、設定生成時の「**転送先ポート**」と一致しているか確認  
   （例: 転送先ポートを `80` のまま生成したのに、PC 側では `8000` で動かしている、など）
4. ポータルで **同じポート番号** を再度入力して設定を再生成
5. 新しい `.conf` ファイルを WireGuard に **上書きインポート**（古いトンネルを削除してから）

### 設定を上書きインポートする手順

1. WireGuard で古いトンネルを選択 → 左下の「**×**」で削除
2. ポータルで設定を再生成してダウンロード
3. 新しい `.conf` ファイルをインポートして有効化

## よくある質問

**Q. トンネルを有効にすると、普段のインターネットに影響しますか？**  
A. 影響しません。VPN サーバーへの通信だけがトンネルを通り、通常のブラウジングなどはそのまま使えます。

**Q. 「ポート XXXX はサーバー上の別のサービスが使用中のため利用できません」と表示される**  
A. そのポートはサーバー側で SSH や Web サーバーなどが既に使用しています。別のポート番号を入力してください。どのポートが使えるかは管理者にお問い合わせください。

**Q. 「ポート XXXX は利用できません。利用可能なポート: …」と表示される**  
A. 管理者が利用できるポートの範囲を制限しています。メッセージに表示された範囲の中からポート番号を選んでください。

**Q. ポート番号を変えたい**  
A. 新しいポート番号でポータルから設定を再生成して、WireGuard にインポートし直してください。古いポートは「使用をやめるときは」の手順で削除してください（管理者の設定によっては管理者への依頼が必要です）。

**Q. 「公開ポート番号」と「転送先ポート」の違いは？**  
A. 「公開ポート番号」は**外部からアクセスするときの番号**（例: `http://example.com:11090` の `11090`）です。「転送先ポート」は**自分の PC で Web サーバーが待ち受けている番号**（XAMPP の既定なら `80`）です。外部からのアクセスは、公開ポート番号から転送先ポートへ中継されます。

**Q. 転送先ポートだけを変えたい**  
A. 同じ公開ポート番号のまま、転送先ポートを変更して「設定を生成する」を押してください。転送先だけが切り替わります。なお鍵も再発行されるため、新しい `.conf` を WireGuard にインポートし直してください。

**Q. 削除トークンを紛失してしまった**  
A. 同じポート番号で設定を再生成すると新しいトークンが発行されます。その後、新しいトークンで削除してください。または管理者にお問い合わせください。

**Q. ポート番号を忘れた**  
A. `.conf` ファイルのファイル名（例: `wg-client_11090.conf`）でポート番号を確認できます。または管理者にお問い合わせください。

**Q. 「ハンドシェイク」って何ですか？**  
A. PC と VPN サーバーが正常に通信できているかを示す指標です。「直近のハンドシェイク: ○秒前」と表示されていれば正常に接続されています。
